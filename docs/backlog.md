| ID | História de usuário | Sprint |
|---|---|---|
| US01 | Como gerente de TI, quero uma API que entregue a lista de pontos e o status, para que o app use os dados do sistema existente. | S1 |
| US02 | Como técnico, quero entrar no app com usuário e senha, para que só a equipe veja os dados da rede. | S1 |
| US03 | Como técnico, quero ver os pontos fora do ar e há quanto tempo estão assim, para saber o que priorizar. | S2 |
| US04 | Como técnico, quero buscar um ponto por nome ou serial, para encontrá-lo rápido. | S2 |
| US05 | Como técnico, quero ver o ponto no mapa com a rota da fibra e abrir o "como chegar", para ir direto ao local. | S2 |
| US06 | Como técnico, quero testar o ponto pelo celular, para confirmar que ele voltou sem ligar para a TI. | S3 |
| US07 | Como técnico, quero registrar o atendimento com foto e localização, mesmo sem sinal, para deixar o serviço documentado. | S3 |
| US08 | Como gerente, quero ser avisado no celular quando um ponto crítico cair, para agir logo. | S4 |
| US09 | Como gerente, quero ver o histórico de atendimentos de cada ponto, para planejar a manutenção. | S4 |
| US10 | Como técnico, quero instalar o app por APK, para usar sem depender de loja. | S4 |
